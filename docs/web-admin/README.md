# Web 管理后台文档

本文档集对应当前 `main` 分支已实现的 Web 管理后台能力。

## 推荐阅读顺序

1. [用户手册](user-guide.md)：从登录开始，了解数据源、迁移、租户、分片和审计的日常操作。
2. [部署与运维手册](deployment.md)：构建、配置、首次启动、密钥管理、备份恢复和故障排查。
3. [API 文档](api.md)：REST 接口、请求示例、任务状态和安全边界。
4. [角色权限矩阵](permissions.md)：四种角色可执行的操作。
5. [认证与安全](authentication.md)：密码、会话、CSRF、登录限流和安全审计。
6. [备份与恢复](backup-restore.md)：管理元数据库在线备份和恢复步骤。
7. [动态租户发现](tenant-discovery.md)：控制库发现预览和显式确认导入。
8. [操作审计](audit.md)、[任务诊断](task-diagnostics.md)、[架构说明](architecture.md)。

## 当前功能边界

已实现的数据源管理、租户生命周期管理、动态租户发现与确认导入、迁移任务、分片规则和结构克隆、操作审计、安全审计及管理元数据库备份，以代码和 API 文档为准。

租户连接的按需测试已实现；定时/批量连接健康巡检、自动故障隔离、远程公网管理部署目前不属于已交付功能。管理 API 当前强制 loopback 监听。
