## 当前版本边界

- Web 管理 API 默认只监听 127.0.0.1:8081，当前代码拒绝非 loopback 监听地址。
- 仓库提供 Vue 3 管理后台源码和 Vite 构建配置；Go 管理服务提供 API，不负责托管前端静态文件。
- 本地开发推荐使用 Vite 开发服务器代理 API。前端构建产物可用于后续本地静态托管集成，但当前仓库没有提供可直接公网部署的 Web/API 一体化部署方案。
- API 与核心包的能力以当前 main 分支实现为准；文档不代表尚未实现的远程访问、TLS 终止或生产级多节点管理能力。

## 发现文档问题

如果实际行为与文档不一致，请以当前代码和测试为准，并通过 Issue/PR 更新文档。涉及权限、安全边界、数据破坏性操作的差异应先停止操作并核实，不要根据旧文档猜测。
