# 操作审计

操作审计页面汇总迁移与分片 DDL 的状态事件，按发生时间倒序排列。支持按操作类型、目标状态、任务、数据源、租户、分片规则和时间范围筛选，并通过分页读取历史记录。

## API

`GET /api/v1/audit-events`

查询参数：

| 参数 | 默认值 | 约束 | 说明 |
|---|---:|---|---|
| kind | 空 | `migration` / `shard_ddl` | 操作类型 |
| status | 空 | queued / running / succeeded / failed / canceled / interrupted | 事件目标状态 |
| task_id | 空 | 最长 128 字符 | 精确匹配任务 ID |
| data_source_id | 空 | 最长 128 字符 | 精确匹配数据源 ID |
| tenant_id | 空 | 最长 128 字符 | 精确匹配租户 ID，仅匹配迁移事件 |
| shard_rule_id | 空 | 最长 128 字符 | 精确匹配分片规则 ID，仅匹配分片 DDL 事件 |
| from | 空 | RFC3339 时间戳 | 起始时间，包含边界 |
| to | 空 | RFC3339 时间戳 | 结束时间，包含边界 |
| limit | 50 | 1–200 | 每页数量 |
| offset | 0 | 0–10000000 | 零起始偏移量 |

`from` 和 `to` 可携带时区偏移；服务端会转换为 UTC。若同时提供，两者必须满足 `from <= to`。

响应：

```json
{
  "items": [],
  "total": 0,
  "limit": 50,
  "offset": 0
}
```

事件字段包括任务 ID、类型、数据源、租户或分片规则、动作、状态变化、操作者标记、请求来源、说明和发生时间。分片 DDL 事件额外提供源表与目标表名称。查询只读管理元数据库，不会访问或修改目标数据库。

## 身份边界

当前服务尚未接入认证与授权。操作者 `local-api` 是固定服务标记，不是真实用户身份；请求来源记录管理 API 看到的远端地址，可能是本机代理地址。管理 API 必须继续绑定 loopback，不得暴露公网。
