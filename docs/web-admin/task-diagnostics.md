# 任务失败诊断

迁移任务和分片 DDL 任务在失败时只保存经过分类的安全诊断，不保存数据库驱动的原始错误文本。驱动错误可能包含连接地址、DSN、SQL 片段、用户名或服务端细节。

任务中心会在失败消息中展示稳定错误码和下一步建议：

| 错误码 | 含义 | 建议 |
|---|---|---|
| `MIGRATION_CHECKSUM_MISMATCH` | 已应用迁移脚本与数据库存档校验和不一致 | 恢复原脚本或新增迁移，不要原地修改已应用脚本 |
| `MIGRATION_VERSION_INVALID` | 目标迁移版本不存在 | 检查版本号和部署的迁移脚本 |
| `MIGRATION_SCRIPT_UNAVAILABLE` | 迁移脚本或文件不可用 | 检查迁移目录和脚本部署 |
| `DATABASE_AUTH_FAILED` | 数据库认证失败 | 检查凭据、认证方式和账号状态 |
| `DATABASE_PERMISSION_DENIED` | 数据库账号权限不足 | 仅授予当前操作所需权限 |
| `DATABASE_UNAVAILABLE` | 无法连接目标数据库 | 检查主机、端口、网络和防火墙 |
| `SQL_SYNTAX_ERROR` | 数据库拒绝 SQL 语句 | 检查 SQL 与数据库版本兼容性 |
| `DATABASE_OBJECT_CONFLICT` | 目标对象或记录已存在 | 检查目标结构和迁移历史 |
| `SHARD_SOURCE_TABLE_MISSING` | 分片 DDL 源物理表不存在 | 检查分片规则与源表名 |
| `SHARD_TARGET_TABLE_EXISTS` | 分片 DDL 目标表已存在 | 先核对目标表归属和结构 |
| `SHARD_DDL_FAILED` | 其他分片 DDL 执行失败 | 检查目标表、审计事件、驱动和 DDL 权限 |

无法识别的错误使用通用诊断码。诊断分类仅依据有限的错误类别和匹配规则，不代表数据库端的根因分析；不要仅凭建议自动重试。取消、超时、部分迁移步骤已完成等风险提示仍以任务状态和审计事件为准。

当前版本不向 API 或审计记录暴露原始数据库错误。需要进一步排查时，应在受控环境中查看数据库服务端日志，并避免把 DSN、凭据或敏感 SQL 复制到工单或共享日志。
